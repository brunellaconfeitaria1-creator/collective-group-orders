# Collective Group Orders

Site simples de pedidos coletivos.

## Antes de publicar
1. No Supabase SQL Editor, execute `supabase-setup.sql`.
2. No Supabase, copie a chave **anon/public** (não use service_role).
3. Abra `app.js` e substitua `COLE_AQUI_A_CHAVE_ANON_PUBLICA_DO_SUPABASE`.
4. Faça commit e conecte o repositório à Vercel.
